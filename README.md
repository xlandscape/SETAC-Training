# SETAC-Training
Hands-on Landscape Ecological Risk Assessment Using the Open Source xLandscape Modelling Framework.
For more information see [Training Intro](https://xlandscape.github.io/SETAC-Training/).  

## Documentation Publishing

The GitHub Pages site is deployed from the `gh-pages` branch.

The version shown in the site header follows the latest GitHub Release, not just git tags. Version tags matching `v*` automatically publish a GitHub Release via GitHub Actions, so the displayed site version stays aligned with the latest released documentation.
